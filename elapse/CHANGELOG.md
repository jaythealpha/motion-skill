# 변경 기록

## 2026-11-01 — 타이타닉·브리타닉 장면 연출 개선

### 공통

- 자료 기반 선체 경로·시각·침수 수위는 유지하면서 설명용 물·입자 효과를 추가했습니다.
- 주요 순간에 저속 재생을 적용하고, 기존 속도 선택과 영상 녹화에도 같은 시간 배율을 사용합니다.
- 화면 비율에 맞춰 자동 카메라를 조정하고 설명 카드·계기를 캔버스 아래로 옮겼습니다. 수동 회전·확대와 도면 모드는 유지합니다.
- 키보드 시간 이동, 접근성 이름, 포커스 표시와 동작 감소 설정에 따른 자동 재생 제한을 보완했습니다.
- 자동 속도 검사는 장면별 저속 구간을 반영하도록 기대 이동량을 계산합니다. 기존 허용 오차는 유지했습니다.

### 타이타닉

- 충돌: 측면 구도, 접촉 물보라, 파문과 표면 거품.
- 침수: 구획 수위에 연결된 유입 입자와 기존 투시 표현.
- 분리: 대표 장면 연구를 바탕으로 한 측면 카메라와 물 효과.
- 하강: 기포, 기존 착저 이벤트 이후의 퇴적물 확산.
- 해저 붕괴: 부위 크기와 실제 그려지는 변형·낙하 위치를 따라가는 근접 구도.
- 모바일 영문 예측 배지와 카메라 버튼의 겹침 수정.
- 별도로 확인할 수 있는 분리 장면 연구 페이지와 재생성 스크립트 포함.

### 브리타닉

- 낮 장면에 맞춘 청록색 수면, 손상 지점의 물 효과와 침수 입자.
- 전복 중 갑판 쪽을 보는 카메라, 수면 거품, 수중 기포와 선수 접지 이후의 퇴적물.
- 얕은 해저에서 수중에 머무는 카메라, 갑판 방향 탐사 구도, 절차적으로 생성한 퇴적물 질감과 부유 입자.
- 하강은 기존 전복 장 안에서 이어집니다. 새로운 두 동강·미래 붕괴 장은 추가하지 않았습니다.
