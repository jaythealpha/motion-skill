# 변경 기록

## 2026-11-03 — 5개 언어·화면 표현·재생 부하 개선

- 추가 외형 개선: WTC 항공기 동체·주익 단면·엔진·조종석, 모서리를 깎은 외벽과 유리/금속 구분, 되감기가 가능한 충돌 개구부와 내부 구조.
- 불규칙한 윤곽과 내부 명암을 가진 16종 화염·연기 질감을 미리 생성해 묶어서 렌더링. 노트르담의 기존 화재 시점에도 적용.
- 에펠탑·대성당·선박과 Unfold 5개 예시에 소재별 표면 높이·거칠기와 빛 반응을 적용. 원본 JSON 10개는 바이트 일치로 보존.
- 브리타닉 부착 생물 수가 재렌더링마다 줄어들던 오류 수정. [외형 개선 검증](../docs/reviews/2026-11-03-realism-pass.md).

- 전체 타임라인과 대표 장면에서 영어·한국어·일본어·중국어 간체·스페인어 지원. 영어 기본값, 갤러리 언어 전달, 독립 HTML의 언어 기억, 재생 상태를 유지하는 전환.
- 선박·건물 카메라의 단계적 확대를 연속적인 구도로 변경하고, 모바일 타이타닉 해저의 초기 화면 누락과 설명·카메라 버튼 겹침 수정.
- 조명·재질·주변 건물 표현 보완, WTC 외벽의 무늬 간섭 제거. 추가 도시 형상은 측량 자료가 아닌 설명용 추정.
- 화염·연기·분진 인스턴싱, 설명창 갱신 횟수 제한, 날짜 포맷 캐시, 입력 이벤트 렌더링 통합.
- 같은 네이티브 GPU 장면의 그리기 호출 158→35, 4초간 계기 갱신 240→47. 전후 모두 약 60fps인 짧은 표본이며 실기기 모바일 성능은 미검증.
- 공개 12개 데모 × 5개 언어 × 375/768/1440px 검사 통과. 원본 모델의 치수·시각·ID·출처와 사실 표기를 보존.
- [상세 검증과 한계](../docs/reviews/2026-11-03-five-locales-rendering.md), [화면 QA](../docs/reviews/2026-11-03-demo-design-qa.md). 원어민 전체 감수와 실사 수준의 자산 정확성을 보증하지 않음.

## 2026-11-01 — 타이타닉·브리타닉 장면 연출 개선

### 공통

- 자료 기반 선체 경로·시각·침수 수위는 유지하면서 설명용 물·입자 효과를 추가했습니다.
- 주요 순간에 저속 재생을 적용하고, 기존 속도 선택과 영상 녹화에도 같은 시간 배율을 사용합니다.
- 화면 비율에 맞춰 자동 카메라를 조정하고 설명 카드·계기를 캔버스 아래로 옮겼습니다. 수동 회전·확대와 도면 모드는 유지합니다.
- 키보드 시간 이동, 접근성 이름, 포커스 표시와 동작 감소 설정에 따른 자동 재생 제한을 보완했습니다.
- 자동 속도 검사는 장면별 저속 구간을 반영하도록 기대 이동량을 계산합니다. 기존 허용 오차는 유지했습니다.

### 타이타닉

- 충돌: 측면 구도, 접촉 물보라, 파문과 표면 거품.
- 침수: 구획 수위에 연결된 유입 입자와 기존 투시 표현.
- 분리: 대표 장면 연구를 바탕으로 한 측면 카메라와 물 효과.
- 하강: 기포, 기존 착저 이벤트 이후의 퇴적물 확산.
- 해저 붕괴: 부위 크기와 실제 그려지는 변형·낙하 위치를 따라가는 근접 구도.
- 모바일 영문 예측 배지와 카메라 버튼의 겹침 수정.
- 별도로 확인할 수 있는 분리 장면 연구 페이지와 재생성 스크립트 포함.

### 브리타닉

- 낮 장면에 맞춘 청록색 수면, 손상 지점의 물 효과와 침수 입자.
- 전복 중 갑판 쪽을 보는 카메라, 수면 거품, 수중 기포와 선수 접지 이후의 퇴적물.
- 얕은 해저에서 수중에 머무는 카메라, 갑판 방향 탐사 구도, 절차적으로 생성한 퇴적물 질감과 부유 입자.
- 하강은 기존 전복 장 안에서 이어집니다. 새로운 두 동강·미래 붕괴 장은 추가하지 않았습니다.
