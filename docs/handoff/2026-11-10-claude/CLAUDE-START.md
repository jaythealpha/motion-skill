Unfold / Elapse 프로젝트 개발을 인수인계받아 줘.

기존 미추적 초안 2개와 이미 추적 중인 trials/robot-dawn-2026-11-05/ 파일도 보존해.
~/.claude/skills 또는 ~/.agents/skills에 설치된 스킬 문서는 저장소와 내용이 다르므로
슬래시 명령이 자동 선택한 설치본을 최신이라고 가정하지 말고 저장소 문서를 기준으로 읽어.

이 프로젝트는 기존 앱을 복제하는 것이 아니라, 실제 자료를 근거로
제품 구조(Unfold)와 시간에 따른 변화(Elapse)를 탐색하는 독자적인 스킬을 만드는 작업이야.
기존 사건·인물 기록·날짜·사실값은 보존하고, 형상·배치·움직임의 추정은 명시해.
사건을 자극적으로 소비하기보다 기억해야 할 사실과 서로를 도운 사람들의 기록을 남기는 목적이야.

먼저 현재 Git 상태와 인계 스냅샷이 같은지 확인하고, 코드 구조와 실행·검수 방법을 파악해.
불필요한 중간 확인은 하지 말고 합리적인 판단으로 진행하되,

현재는 인계 확인과 읽기 전용 상태 점검까지만 진행한 뒤,
최신 상태·확인된 제한·우선순위를 짧게 알려 줘. 이후 내가 다음 작업을 지정할게.

테스트 통과를 실제 고증·실측·실제 모바일 검수와 동일시하지 마.
영어 기본값과 한국어/일본어/중국어 간체/스페인어를 유지해.
새 주제를 만들라는 요청을 받으면 사람/집단의 기여, 범위가 명확한 사실값,
