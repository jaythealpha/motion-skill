## 현재 기능과 검수 근거

Elapse는 시간에 따른 사건·건축물 변화를 3D 타임라인과 탐사 모드로, Unfold는 기기 구조와 조립 과정을 설명한다. 역사적 근거와 추정을 구분하고, 피해나 사고를 자극적으로 소비하기보다 사람들의 도움과 기록을 보존한다. 기본 언어는 영어이며 한국어·일본어·중국어·스페인어를 지원한다.

Sydney 전체 타임라인에 쉘·타일·물·실내 표현을 개선했고, WTC에는 외벽, 조명과 후처리 등을 추가했다. 기존 기록과 시간 데이터는 유지했다. 검수 범위, 실제 기기 한계와 측정치는 [시드니/WTC 검수 보고서](../../reviews/2026-11-10-opera-wtc-release/design-qa.md)와 [시드니 대표 장면 검수](../../reviews/2026-11-10-opera-fable/design-qa.md)를 참조한다. 이전 테스트는 당시의 증거이며 새 변경을 보증하지 않는다.

## JANCTION 비교 실험과 결정

사용자는 실제 렌더 품질 차이가 충분하지 않다고 판단하여 **JANCTION 렌더 사용을 중단**하기로 했다. 더 이상 호출하거나 비용을 발생시키지 않는다. [동일 카메라 비교 화면](comparison-delivery.html)과 결과 PNG를 이 폴더에 보존했다. 결과는 정적 파일이며 공개 데모에 적용된 개선이 아니다.

Three.js의 누락된 21개 선 객체·6,607개 선분을 띠로 근사하고 원본 타일 생성 패턴을 Blender 노드에 옮겼으며 하늘과 물을 근사했다. 타일 줄눈은 확대해도 일부 희미하다. `contrast-v6`는 가독성을 위해 대비를 인위적으로 높였으므로 실제 타일의 검증된 색상이 아니다. 조명·반사·수면은 원본과 일치하지 않는다. 실사 또는 실측 모델로 표현하지 않는다.

이번 비교 작업 마지막 3개 렌더의 서비스 보고 비용은 각 0엔, 총 27.07 GPU초이며 정산 확정은 확인하지 못했다. 모든 작업의 최대 과금 설정은 0엔이었다. 예제 스크립트와 카메라 메타데이터는 참고용으로 보존했으나, 51MB GLB와 기존 임시 서버·API 작업 정보는 저장소에 없다. 따라서 이 폴더만으로 Blender 장면을 재실행할 수는 없다. API 키, 임시 다운로드 URL, 계정 정보는 저장소에 포함하지 않는다.

## 다음 작업

사용자는 Fable 5.2를 활용해 나머지 예시를 개선하고 싶어 한다. 우선 각 예시별 현 상태와 실제 범위를 확인하고 동일 시점·동일 카메라의 전후 비교, 출처·추정 구분, 다섯 언어, 모바일·데스크톱, 재생 성능 및 기록 보존을 검수한다. 모델 출력은 실제 시각 품질을 보장하지 않으며, API 비용과 실행 예산을 사전에 확인한다. 남은 Elapse 본편은 Titanic, Britannic, Eiffel Tower, Notre-Dame, Sampoong, Seongsu Bridge 총 6개다. Unfold 본편 5개는 별도 범위다. 대표 장면은 본편 수와 따로 센다. 이전 대화의 7개라는 계산은 오류였다.

시드니 대표 작업의 기록된 CLI API 비용 추정은 $1.730282, WTC 작업은 $0.985072다. 예시당 시드니 기준 2~4회로 단순 추정하면 Elapse 6개 $20.76~$41.52, Unfold까지 11개 $38.06~$76.13이다. 이는 견적이 아니며 맥락 길이·출력량·수정 횟수에 따라 달라진다. Fable 정규 API 요금은 변경 가능하므로 호출 전 공식 가격과 예산을 확인한다.

## 실행과 보안

루트와 각 스킬의 README 및 `AGENTS.md`를 먼저 확인하고 기존 패키지 스크립트를 사용한다. 예제 HTML은 빌드 결과이므로 소스와 생성 경로를 확인한 후 수정한다. 키는 사용자가 관리하는 안전한 저장소에서 별도 설정하며, 코드·로그·Git·인계 자료에 기록하지 않는다. 사용자 허가 없이 외부 API에 민감한 소스나 자료를 보내지 않는다.

다른 환경에서 작업을 시작할 때: 저장소를 클론하고 이 문서 및 연결된 검수 자료를 읽고, `git status`와 원격 브랜치를 확인한 뒤 필요한 의존성·테스트를 실행한다. 과거 로컬 경로·임시 서버·인증은 새 환경에서 이용할 수 없다고 가정한다.
