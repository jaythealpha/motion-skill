# 세계무역센터 전체 타임라인 개선

## 구현 내용

- 2001년 테러 전 → 북·남타워 충돌 → 남·북타워 붕괴 → 7 WTC 붕괴 → 수습 → 2018년 주요 재건까지 연결.
- 두 충돌과 세 붕괴에 각각 자동 관찰 카메라와 감속 구간 적용. 수동 시점·탐사 모드 유지.
- 일반형 항공기의 동체·날개·엔진·팬·창, 1024×2048 절차적 외벽 텍스처, 연기·화염·분진 개선.
- 붕괴 상부와 하부 외벽을 분리하고 7 WTC 전체를 수직으로 압축하던 표현 교체.
- 0.25×·0.5× 관찰 속도 추가, 설명·기록 시각·높이 카드 위치 고정.
- 이번 추가 디테일: 옥상 가장자리, 환기 설비·루버, 붕괴 경계의 바닥 격자·기둥·코어. 모두 추정 도해임을 페이지와 모델 생성기에 명시.

## 사실과 표현의 경계

공식 출처의 사건 시각·순서와 주요 재건 이정표를 유지한다. 모션 길이, 항공기 경로, 옥상·단면 형상, 주변 건물과 입자는 설명용 추정이다. 실제 시공 도면·충돌 역학·NIST 물리 시뮬레이션의 재현이 아니다. 사람·피해자·유해를 그리지 않는다. 2018년 이정표는 현재 단지 전체나 재건 완료를 의미하지 않는다.

## 커밋 범위

WTC 모델·생성기·렌더러·대표 장면·자동 검증·문서와 실행에 필요한 공통 Elapse 엔진을 포함한다. 건축 분기에서 정적으로 불러오는 에펠탑·노트르담 모듈과 해당 예제/검증도 함께 기록하여 새 체크아웃에서 의존성이 누락되지 않게 한다. 기존 Unfold, 라이선스 정리, 루트 README와 설치/공개 준비 변경은 이번 커밋에 포함하지 않는다. 해양 엔진 공통 의존성은 현재 작업 상태를 보존한다. 비공개 저장소 상태를 유지한다.
