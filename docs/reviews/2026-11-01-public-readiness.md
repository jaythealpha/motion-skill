1. Git HEAD를 새 체크아웃으로 내보냄.
2. `INSTALL.md`의 복사 명령을 사용하되 목적지만 격리 폴더로 대체. 공백이 포함된 설치 경로 사용.
3. 같은 명령을 다시 실행해 기존 두 폴더를 건너뛰는 것 확인.

6. 설치 안내의 첫 데이터 검사·빌드 명령을 실제 실행. S24와 타이타닉 통과.

## 데모

격리 설치로 생성한 8개 HTML을 1440px 브라우저에서 열고 직접 캡처를 확인했습니다. 모두 캔버스와 제목이 표시됐고, 가로 넘침과 콘솔 경고·오류는 없었습니다. 이번 검사는 모든 상태를 검사하는 전체 Gate 2의 재실행이 아니라 새 설치 산출물의 기본 동작 검사입니다.

- 768px: 아이폰 듀오의 분해 상태와 라벨 배치 확인.
