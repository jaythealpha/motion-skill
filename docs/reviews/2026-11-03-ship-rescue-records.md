## 수치·시각·연출 검토

- 영국 보고서의712명 서술과 NARA가 설명하는 명부의706명처럼 자료·범위 차이가 있어, 카르파티아호의 단일 무쟁점 총인원을 새 표의 대표값으로 채택하지 않았다. 두 값은 합산하지 않는다.
- 로우의4명은 해당 증언의 당시 생존 상태를 가리킨다. 최종 생존 및 전체 구조 합계와 구분한다.
- Press 발행일1916-11-25와 브리타닉 사건일1916-11-21을 별도 값으로 보존한다.
- 개인 활동은 날짜 단위로만 연결했다. 인물별 분 단위 시각, 대화, 심리, 이동 경로를 만들지 않았다.
- 연결된 `gone`/`abandon`은 침몰 맥락이다. 실제 구조 위치나 구조 시각이라고 표시하지 않으며 각 기록의 시간 설명에서도 이를 명시한다. 해저 모델 옆에 가상 구조 활동을 새로 그리지 않았다.
- 영국/미국 조사 자료는 웹 전사본, 박물관은 회고를 소개한 해설, 도서관은 스크랩북 발췌, 신문은 당시 전언 보도로 구분해 적었다. 원문 전체를 직접 확인했다거나 기관 공인 번역이라고 주장하지 않는다.
- 원문 사진·신문 이미지·음성·긴 인용문 없이 사실을 새 문장으로 요약했다.

## 구현과 보존

`research/records/titanic.json`, `britannic.json`에 각각3건을 추가했다. 기존 `discovery`/`survey` ID와 본문은 유지했다. 전체는18개 기록·15개 사실값이다. 새 기록6건의 제목·행동·기억할 것·미확정 사항·시간 설명을 영어·한국어·일본어·중국어 간체·스페인어로 작성했다. 갤러리의 두 카드 설명과 캐시 키도 갱신했다.

기존 엔진·도형·트랙·카메라·이벤트 시각은 변경하지 않았다. 이전 커밋과 두 모델을 의미 비교해 `remembrance` 외의 데이터가 동일함을 확인했다. 타이타닉 단일 HTML, 브리타닉 단일 HTML과 타이타닉 모델을 포함하는 분리 대표 장면 HTML을 다시 빌드했다. 기존 언어 저장값과 사용자 설치 폴더는 덮어쓰지 않았다.

## 검수

- 기록 브라우저300건:18개 기록 ×5개 언어 ×375/768/1440px =270건, 나머지30건은 직접 링크·포커스·3D 왕복·언어·교통 정지/복귀·WebGL 실패·스크립트 없는 읽기 경로다. 두 배도3D 왕복, WebGL 실패, 스크립트 없는 영어 읽기 검사에 포함한다.
- 영향받는3D 타임라인2개 및 타이타닉 대표 장면:45개 언어/화면 조합 검사.
- Elapse 단위 테스트142개를 UTC와 Asia/Seoul에서 실행. 새 검사는 구조 수치의 범위, 회고의 사건 구분, 발행일과 사건일 구분, 기존 링크·날짜 정밀도를 다룬다.
- 두 모델 Gate1, 공통/언어 테스트11개, 공유 파일 동기화와 공백 검사.
- 새 임시 설치 폴더의 재생성11개 HTML을 원본과 바이트 단위 비교. 사용자의 실제 설치를 갱신했다는 의미는 아니다.

개별 검사 결과와 스크린샷은 `trials/ship-help-2026-11-03/`에 남긴다. 공개 배포 후에는 배포 커밋·파일 해시·공개 읽기/3D/갤러리 흐름을 별도로 확인한다. 자동 검수는 실기기, 스크린리더, 독립 사료 전문가·원어민 검수를 대체하지 않는다.
