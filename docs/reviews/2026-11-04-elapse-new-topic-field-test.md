# Elapse new-topic workflow: people, facts and Sydney Opera House

Date2026-11-04. Scope: change the default new-topic authoring workflow, exercise actual research→evidence→HTML→browser review→isolated install→authorized public Pages deployment. This is one real agent field test and deterministic coverage tests, not proof of independent historical authentication or an always-running research service.

## Changes and preservation

The new default `build-topic.mjs` merges an agent-researched evidence bundle with an independently authored scene. It sets `meta.researchProfile:people-facts-v1`, validates contributor names/collectives, five-language roles and supporting source references, and requires finite numeric facts with scope/units/evidence. Existing Gate1 and the low-level builder enforce the profile on a compiled model, so a direct rebuild cannot silently lose its evidence. A documented lack of evidence can pass only as an explicitly sourced gap whose reason occurs in a visible record's unknowns in all five languages. Its report retains the gap; no name or count is invented.

The compiler runs schema/Gate1/locales before replacing existing deliverables. Negative tests verify that failed coverage preserves an existing HTML and sibling model. It does not fetch the web or certify that a source claim is true. The skill instructs the agent to retrieve original sources and assess them before compilation; the field run actually did this. Legacy scene-only builders and seven existing historical models remain supported. The seven model JSON files were independently byte-compared against the previous commit and preserved. Unrelated drafts and existing user installations were not overwritten.

Generic `check-topic.mjs` accepts a local HTML or public URL; it checks five-language records at375/768/1440, values/scopes, actual selection/focus, native deep links, optional3D context/return, WebGL failure and script-disabled English. `check_opera.mjs` separately checks time reversal, styles, fixed slots, five stops, actual renderer selection, explicit hall cutaway, unbuilt-stop restrictions and premature glazing. These supplement full Gate2 and source review rather than replacing them.

## Actual source research

See [Sydney research notes](../../elapse/research/sydney-notes.md) for the six retrieved source pages, source locators and limitations. Sources include the Opera House's creators/architect/spherical-solution/renewal accounts, NFSA's attributed collection notes, and ARM's first-person project account. NSW archive full pages and the Parliament dimension PDF could not be fully retrieved; search-only snippets and that PDF were excluded from verified evidence. No photos, plans, film, audio, article prose or source meshes are bundled.

Five records have seven contributor entries and three factual values: NFSA's **about10,000 participants across1959–1973**, **18 Concert Hall reflectors** and **0.4m relative stage lowering** in the2022 renewal. These populations/units/scopes are distinct.1972 film metadata is not the1973 opening;12 August2022 article publication is not the July reopening; exact days are not added to a month-only source. Utzon's departure and Hall's contribution are recognized without invented motives or private dialogue. Gadigal/Tubowgule acknowledgement is retained separately from the2023 plaques.

## Visual and behavioral review

Existing typography, colors, panels, language handling, focus and44px controls remain. The new dedicated template uses independently estimated podium/shell/rib/glazing and an explicit hall cutaway. Its rounded120×180×67m envelope, nine sail groups, profiles, detail coordinates and work sequence are estimates, not measured CAD or exact spherical geometry. It is an educational architectural context, not a claim of photorealism or compliance with a structural/acoustic/accessibility plan.

Review caught and corrected a long dimension value clipped in its fixed gauge and glazing visible before fit-out. Inspection tests were strengthened to send actual bubbling select events and assert that the renderer received each stop, avoiding a false pass from changing only the displayed option. Blueprint's pre-construction view now has a schematic site grid rather than future windows. The grid, quay, water and site are explicitly illustrative, not a surveyed preconstruction site plan.

An initial parallel software-renderer speed check failed while competing for rendering resources. A subsequent hardware-path check retained the same speed tolerance. It measured each playback preset against elapsed time; this is browser playback evidence, not a physical-device FPS claim. Final per-run results are retained in `trials/new-topic-2026-11-04/`; failures are not deleted or relabelled as passing.

Final local and public counts, hashes, installed build comparisons and deployed commit are recorded separately in `trials/new-topic-2026-11-04/RELEASE.json` after completion. UI acceptance requires no open P0/P1/P2 findings within the checked scope. Unverified: physical devices, screen-reader traversal, independent historical expert and native-language approval, exact structural morphology and measured audio performance. No blanket unattended authentication-renewal or crash-recovery claim is made.
