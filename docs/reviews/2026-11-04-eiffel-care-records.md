## 현대 기록과 역사 장면

기록에는 1884년 설계와 2019·2024년 유지보수를 포함하지만 3D 타임라인은 계속 1887–1889년 건설 도해다. 현대 기록의 시간 설명·미확정 사항에는 연결된 1889년 장면이 현대 설비나 실제 작업자의 동선·현장이 아님을 다섯 언어로 명시했다. 기록을 위해 현대 부품이나 인물을 옛 장면에 추가하지 않았다. 주제의 기존 제목과 건설 연도는 유지한다.

기관 기록과 편집자의 기억할 점을 분리했다. 개인별 공적, 동기, 대화, 작업 시간표, 사고나 부상 수, 전체 노동자 명부를 만들지 않았다. 작업자 안전에 관한 기관 설명은 독립 안전 감사나 이 프로젝트의 안전 인증이 아니다. 사진·도면·문서 스캔·음성·영상은 포함하지 않고 사실을 새 문장으로 요약했다.

## 검수 기준과 증거

기존 읽기 UI의 레이아웃·폰트·색상·반응형·44px 이상 조작 영역을 유지한다. 새 장문과 일본어·중국어·스페인어를 375/768/1440px에서 확인한다. 신규 레이아웃이나 외형 변경은 없다. 기록 선택·키보드 포커스·언어 전달·3D 왕복 시각/카메라 보존·WebGL 실패·JavaScript 없는 영어 읽기를 검사한다. 새 테스트는 에펠탑에도 후자의 세 경로를 포함한다.

실행 증거는 `trials/eiffel-care-2026-11-04/`와 해당 로그에 보관한다. 단위 검사는 기존 기록의 ID와 공장/작업조 범위, 현대 기록의 연도 단위와 1889 장면 맥락을 확인한다. `npm test --prefix elapse`는 UTC와 Asia/Seoul에서 실행한다. Gate1·언어 검사, 기록 브라우저 검사, 에펠탑 3D 언어/화면 검사, 갤러리 언어 연결, 새 설치 폴더 HTML 재생성·공개 파일 해시를 확인한다.

최종 결과는 검수 종료 후 아래에 기록한다. 실물 모바일 기기·스크린리더 전 과정·독립 사료 전문가·원어민 승인은 미검증이다. 자동 검사로 이 범위를 대신했다고 주장하지 않는다.

## 로컬 최종 판정

`passed`: 확인한 범위에 열린 P0/P1/P2 문제 없음. 기록 화면 430건(26개 기록 × 5언어 × 3폭 = 390건 및 전환·대체 화면 등 40건), 에펠탑3D 15건, 갤러리 언어/화면 15조합과 키보드·언어 저장·무스크립트 검사 통과. 375px 한국어 도장 기록, 768px 일본어 승강기 기록, 1440px 한국어 공장/리벳 기록 캡처를 직접 검토했다. 긴 문구와 번호의 줄바꿈·가로 넘침·기존 색상/정렬에서 수정이 필요한 문제는 없었다.

Elapse 단위 테스트 146건을 UTC와 Asia/Seoul에서 각각 통과, 공유 테스트 8건과 언어 테스트 3건 통과. Gate1·언어 필드 검사·공유 코드 동기화·diff 공백 검사 통과. 새 격리 설치 폴더에서 전체 타임라인7개·대표 장면3개·휴대폰1개를 재생성해 11건 모두 바이트 일치. 기존 사용자 설치 폴더는 변경하지 않았다. `remembrance`를 제외한 에펠탑 모델은 이전 커밋과 의미 비교해 동일함을 확인했다.

공개 배포는 기존 main/Pages 경로로 반영하며 배포 커밋, 실제 공개 파일 해시·브라우저·설치 재현의 최종 증거는 `trials/eiffel-care-2026-11-04/RELEASE.json`에 별도로 기록한다. 로컬 검수 자체를 공개 배포 검증으로 간주하지 않는다.
